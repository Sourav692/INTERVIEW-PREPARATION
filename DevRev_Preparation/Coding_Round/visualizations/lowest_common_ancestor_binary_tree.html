236 · Lowest Common Ancestor (general tree)

The deepest node that contains both.

The problem, in plain words

Given two nodes in a tree, find their deepest shared parent — the lowest node that has both of them below it.

DevRev framing: two sub-tasks or two comments in a thread — what is the closest item that contains both? A task tree has no ordering, so (unlike a BST) you cannot navigate by comparison.
looking atremembered / keptmatch / answerruled out

The smart way — one DFS, let the answer bubble up

Search once. A node reports itself upward if it is one of the two targets, or if a target was found below it. The node that gets a non-null report from both its left and right sides is where the two paths split — that is the answer.

Speed: visit each node once — O(n) time, O(height) stack. (If a node is an ancestor of the other, that node is itself the answer.)

When you’d use this

See "deepest common ancestor of two nodes in a general tree"? One DFS that returns a node if it holds either target; the node whose both sides return non-null is the LCA.
