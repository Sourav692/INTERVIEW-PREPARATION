Downstream of a Failure (Blast Radius)

Who is affected when a task fails?

The problem, in plain words

Services and tasks depend on each other (arrows point from a task to the tasks that depend on it). One task fails — which others are affected?

DevRev framing: incident blast radius. When a service breaks, walk the dependency graph to find every task downstream of it. BFS also tells you how many hops away each one is.

The smart way — BFS/DFS out from the failed node

Start at the failure, mark it, and fan out to everything it points to, using a visited set so you never revisit (and never loop on a cycle). Everything you reach is affected.

Speed: each task and arrow visited once — O(V + E) (vs re-scanning every edge each round, O(V·E)).

When you’d use this

See "who is affected / blast radius / everything downstream of X"? BFS/DFS from the source with a visited set. Reverse the arrows to trace upstream (root cause).
