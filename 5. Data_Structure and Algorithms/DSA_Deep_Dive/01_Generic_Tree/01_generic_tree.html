🌳 Generic (N-ary) Trees

Any number of children per node — walked with DFS or BFS.

The idea & vocabulary

A generic (N-ary) tree: every node has any number of children. One parent each, except the root; no cycles.

TermMeaning
Root / Leafthe top node (no parent) / a node with no children
Depthedges from the root down to a node (root = 0)
Heightedges on the longest path down to a leaf (leaf = 0)

Hook: you fall down to your depth; you grow up to your height.

① DFS Pre-order (Node → children)

Depth-first, visiting a node before its children (top-down). Used for copy / serialize.

visit order

② DFS Post-order (children → Node)

Depth-first, visiting a node after all its children (bottom-up). Used for size / height / delete.

visit order

③ BFS Level-order (a queue)

Breadth-first: visit level by level using a queue (FIFO). Used for shortest reach.

queue (front → back)

④ Build a tree from flat {id, parent_id} rows

How databases store trees: index every row by id in a hash map, then link each node to its parent in one O(n) pass.
