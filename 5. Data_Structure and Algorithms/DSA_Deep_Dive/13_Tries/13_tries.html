🔤 Tries (Prefix Trees)

Insert, search, and prefix-match on a character-keyed tree.

insert / search / prefix

The idea

A trie stores strings character by character; shared prefixes share nodes. insert / search / prefix all cost O(word length), independent of word count.

A node has a children map + an is-word flag. Reaching a node = the string is a prefix; a word ends there only if the flag is set.
