The core flip

Preorder always gives you the root first. Inorder tells you which values fall left vs right of that root — everything before it in inorder belongs to the left subtree, everything after belongs to the right. Combine both: pop the next preorder value as the root, use it to split the current inorder range, and recurse.

Why a hash map beats scanning for the split: naively calling inorder.index(value) at every node costs O(n) per lookup → O(n²) total. Precomputing value → index in a dict turns that into an O(1) lookup, bringing the whole algorithm down to O(n). Passing index bounds instead of slicing the arrays also avoids the O(n) cost of creating new list slices at every recursive call.

Optimal Solution — Hash Map + Index Bounds · O(n) time, O(n) space

def build_tree(preorder, inorder):
    idx = {v: i for i, v in enumerate(inorder)}   # value -> its position in inorder
    pre_ptr = [0]                                  # current position in preorder

    def helper(lo, hi):               # build the subtree covering inorder[lo..hi]
        if lo > hi:
            return None
        val = preorder[pre_ptr[0]]    # next preorder value is this subtree's root
        pre_ptr[0] += 1
        node = TreeNode(val)
        m = idx[val]                  # where root splits inorder (O(1) lookup)
        node.left = helper(lo, m - 1)      # left part first (preorder does left first)
        node.right = helper(m + 1, hi)     # then right part
        return node

    return helper(0, len(inorder) - 1)

Hash map build is O(n); each of n nodes does O(1) split work → O(n) time overall. Map plus recursion → O(n) space.

The core flip

To rebuild a tree exactly, the text has to capture shape, not just values — including where children are missing. Writing an explicit marker (e.g. #) for every empty child turns a simple preorder walk into a lossless snapshot: reading tokens back in the exact same order reconstructs the tree with zero ambiguity.

tree = [1, 2, 3, null, null, 4, 5]

(not started)
Press "Step" to begin. Preorder DFS: visit root (1) first.
Why markers are non-negotiable: without a marker for empty children, the sequence 1,2,3 could describe several different tree shapes — a chain, or 2 and 3 both being children of 1, or other configurations. Writing 1,2,#,#,3,#,# makes exactly one tree shape consistent with the text, because deserialize always knows precisely when to stop building a subtree.

Optimal Solution — Preorder with Null Markers · O(n) time, O(n) space

def serialize(root):
    out = []
    def dfs(node):
        if not node:
            out.append("#")            # marker for a missing child
            return
        out.append(str(node.val))
        dfs(node.left)
        dfs(node.right)
    dfs(root)
    return ",".join(out)

def deserialize(data):
    vals = iter(data.split(","))       # read tokens in the SAME order they were written
    def build():
        v = next(vals)
        if v == "#":
            return None
        node = TreeNode(int(v))
        node.left = build()            # left subtree first (matches preorder)
        node.right = build()
        return node
    return build()

Every node (and every empty slot) visited exactly once, both directions → O(n) time. Output string and recursion → O(n) space.
