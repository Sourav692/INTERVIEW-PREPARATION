🧩 Binary Patterns — Interview Cheat Sheet

A few ideas cover the whole topic. Learn to spot which one a question wants.

⊕ XOR Cancels Pairs

Anything XORed with itself vanishes — so duplicates disappear and the odd one out remains.

The tell (how to spot it): You need the unmatched item, or to add/compare without arithmetic.

How it works: XOR everything together; matched values cancel to 0, leaving the single leftover (or a partial sum).

Problems here that use it: Missing Number Sum of Two Integers

Say this in the interview:
“XOR cancels equal pairs, so XORing indices with values leaves just the missing/odd one — O(n), no overflow.”

🧩 Bit Tricks (shift, mask, n&(n-1))

Small operations on bits build and take apart numbers super fast.

The tell (how to spot it): You count, reverse, or build a number bit by bit.

How it works: Shift to move bits, mask to isolate them, and use `n & (n-1)` to clear the lowest set bit.

Problems here that use it: Number of 1 Bits Reverse Bits Counting Bits

Say this in the interview:
“I’ll use bit shifts and n&(n-1) to process the bits directly — that’s O(bits), essentially constant.”

Talking through any Binary problem

1. Write out a few bits by hand to see the pattern.

2. Recall the toolkit: XOR (cancel pairs / add bits), AND+shift (carry / clear bit), OR/shift (build), mask (fixed width).

3. Mind fixed width & signs — in most languages you mask to 32 bits and handle negatives.
