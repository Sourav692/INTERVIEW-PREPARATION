BFS Level-by-Level Pattern

Binary Tree Level Order Traversal — a queue naturally groups nodes by level

The core flip

"Level by level" is exactly what a queue gives you for free: at any moment, everything currently sitting in the queue belongs to one level — because every node was enqueued by its parent, and all parents of a given level were processed together in the previous step. The trick is to snapshot the queue's size before processing, so you know exactly how many nodes belong to the current level before their children start getting added.

Why snapshot len(q) before the loop: if you read the queue's length freshly on each iteration instead of freezing it upfront, children pushed for the next level would get counted as part of the current level's processing loop — silently merging two levels into one. Freezing the count first is what cleanly separates "process this level" from "queue up the next one."

Optimal Solution — BFS with a Queue · O(n) time, O(n) space

from collections import deque

def level_order(root):
    res = []
    if not root:
        return res
    q = deque([root])
    while q:
        level = []
        for _ in range(len(q)):        # snapshot: current queue = exactly one level
            node = q.popleft()
            level.append(node.val)
            if node.left:  q.append(node.left)   # push next level's nodes
            if node.right: q.append(node.right)
        res.append(level)              # this level is finished
    return res

Every node enqueued and dequeued exactly once → O(n) time. The queue can hold up to one full level (widest row) at once, plus the output stores every node → O(n) space.

Alternative — DFS tagged by depth: recurse with a depth counter; the first time you reach a new depth, create its list in the result, then append. Same O(n) time, but O(h) space instead of O(n) for the traversal itself (plus output either way) — useful if you want to avoid an explicit queue. 
def level_order_dfs(root):
    res = []
    def dfs(node, depth):
        if not node:
            return
        if depth == len(res):
            res.append([])             # first time reaching this depth
        res[depth].append(node.val)
        dfs(node.left, depth + 1)
        dfs(node.right, depth + 1)
    dfs(root, 0)
    return res
