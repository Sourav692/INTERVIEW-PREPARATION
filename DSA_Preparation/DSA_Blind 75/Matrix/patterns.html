🧩 Matrix Patterns — Interview Cheat Sheet

A few ideas cover the whole topic. Learn to spot which one a question wants.

♻️ In-Place Grid Tricks

Rearrange a grid using itself as scratch paper — no second grid.

The tell (how to spot it): You must transform a matrix in place with O(1) extra space.

How it works: Use the border row/column as flags (set-zeroes), or compose simple moves like transpose + reverse (rotate).

Problems here that use it: Set Matrix Zeroes Rotate Image

Say this in the interview:
“I’ll transform the grid in place — using the first row/col as markers (or transpose+reverse) for O(1) space.”

🧭 Boundary Walking

Trace the outer edges, then shrink inward layer by layer.

The tell (how to spot it): You traverse a grid in a spiral or layered order.

How it works: Keep top/bottom/left/right limits; walk each edge, then move that limit inward until they cross.

Problems here that use it: Spiral Matrix

Say this in the interview:
“I’ll track four shrinking boundaries and trace each edge in turn — O(m×n).”

🌳 Grid Backtracking

Search a maze, marking your trail and erasing it when you turn back.

The tell (how to spot it): You look for a path or word through adjacent cells.

How it works: DFS from each start; mark the current cell used, explore neighbors, then restore it so other paths can use it.

Problems here that use it: Word Search

Say this in the interview:
“I’ll DFS from each cell, marking cells used and restoring on backtrack, pruning as soon as a letter mismatches.”

Talking through any Matrix problem

1. Fix your coordinates: (row, col), and how neighbors/transpose map.

2. Ask for O(1) space: can the grid itself store flags, or can moves compose (transpose+reverse)?

3. For traversals, track boundaries; for path search, backtrack (mark/restore).
