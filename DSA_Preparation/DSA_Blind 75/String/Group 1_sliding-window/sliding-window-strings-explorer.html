The core flip

Keep a window [left, right] that always holds only unique characters. Grow right freely; the moment a repeat would enter, shrink from the left until the duplicate is gone. Each character enters and leaves the window at most once — the whole scan is O(n), not O(n²).

Two valid speeds: shrinking one character at a time with a set is O(n) amortized. Remembering each character's last seen index in a map lets left jump straight past the duplicate in one step — same complexity class, fewer individual operations.

Optimal Solution — Sliding Window + Last-Seen Map · O(n) time, O(min(n, alphabet)) space

def length_of_longest_substring(s: str) -> int:
    last = {}                    # character -> last index we saw it at
    left = best = 0
    for right, c in enumerate(s):
        if c in last and last[c] >= left:
            left = last[c] + 1   # jump left straight past the previous copy
        last[c] = right
        best = max(best, right - left + 1)
    return best

Each index visited by right once, left only moves forward → O(n) total. Map holds at most one entry per distinct character → O(min(n, alphabet size)) space.

The core flip

A window can be turned all-one-letter using window length − (count of its most frequent letter) replacements. Grow the window while that number stays ≤ k; shrink from the left the moment it exceeds k. Track only the running max frequency — no need to fully recompute it on every shrink.

Why maxFreq never needs to decrease: even after shrinking, the recorded maxFreq might be stale (too high) — but that's harmless. A stale (too-large) maxFreq only makes the "needs more than k changes" check stricter, which can never report an invalid window as valid. It just means the window won't grow again until a genuinely larger frequency appears — the max-length answer is unaffected.

Optimal Solution — Sliding Window + Max Frequency Tracker · O(n) time, O(1) space

def character_replacement(s: str, k: int) -> int:
    count = {}          # letter counts inside the window
    left = best = maxf = 0
    for right in range(len(s)):
        count[s[right]] = count.get(s[right], 0) + 1
        maxf = max(maxf, count[s[right]])       # most frequent letter in the window
        # window needs more than k replacements -> shrink
        while (right - left + 1) - maxf > k:
            count[s[left]] -= 1
            left += 1
        best = max(best, right - left + 1)
    return best

Each index visited by right once, left only moves forward → O(n) time. Count map has at most 26 letters → O(1) space.

The core flip

This is a grow-then-shrink window: expand right until the window covers every character of t (with repeats), then squeeze left as far as possible while it still covers — recording the smallest valid window along the way. A single missing counter tracks coverage in O(1) per step, instead of re-scanning counts.

Why decrement need below zero is fine: extra copies of a needed character just make need[c] go negative — harmless bookkeeping. It only matters when checking before decrementing/incrementing whether we cross the zero boundary, since that's the moment coverage is gained or lost.

Optimal Solution — Grow/Shrink Window + Missing Counter · O(n) time, O(m) space

from collections import Counter

def min_window(s: str, t: str) -> str:
    if not t or not s:
        return ""
    need = Counter(t)              # remaining count needed per character
    missing = len(t)                # total characters still to cover (with repeats)
    left = 0
    best = (float("inf"), 0, 0)     # (length, start, end+1)
    for right, c in enumerate(s):
        if need[c] > 0:
            missing -= 1
        need[c] -= 1
        while missing == 0:         # window covers all of t -> try to shrink
            if right - left + 1 < best[0]:
                best = (right - left + 1, left, right + 1)
            need[s[left]] += 1
            if need[s[left]] > 0:
                missing += 1        # dropping this char breaks coverage
            left += 1
    return "" if best[0] == float("inf") else s[best[1]:best[2]]

Each index visited by right once and by left at most once → O(n) time (n = len(s)). Counter holds at most m distinct characters from t → O(m) space.
