The core flip

Prerequisites form a directed graph. You can finish every course exactly when there's no cycle — no course indirectly requires itself. Two equivalent lenses: DFS coloring (unvisited / in-progress / safe) spots a back-edge into an in-progress node; Kahn's algorithm repeatedly peels off courses with zero remaining prerequisites — if any courses are left stuck, they're in a cycle.

Why "courses taken == numCourses" is the whole check: if a cycle exists, every course in that cycle permanently has in-degree ≥ 1 (each is waiting on another in the same cycle) — so the queue starves before reaching them. Counting how many courses got successfully taken and comparing to the total is a clean, complete cycle detector with zero extra logic.

Optimal Solution — Kahn's Topological Sort · O(V+E) time, O(V+E) space

from collections import defaultdict, deque

def can_finish(numCourses, prerequisites):
    graph = defaultdict(list)              # course -> courses it unlocks
    indeg = [0] * numCourses               # remaining prerequisites per course
    for a, b in prerequisites:
        graph[b].append(a)                 # finishing b unlocks a
        indeg[a] += 1

    q = deque([c for c in range(numCourses) if indeg[c] == 0])   # ready to take now
    done = 0
    while q:
        c = q.popleft(); done += 1
        for nxt in graph[c]:
            indeg[nxt] -= 1                # nxt no longer needs c
            if indeg[nxt] == 0:
                q.append(nxt)               # now nxt is ready too

    return done == numCourses              # took everything -> no cycle

Each node enqueued/dequeued once, each edge relaxed once → O(V+E) time. Adjacency list, in-degree array, queue → O(V+E) space.

The core flip

Words sorted in an unknown alphabet leak ordering clues: the first differing letter between two adjacent words tells you "this letter comes before that one" — exactly one directed edge per adjacent word pair. Topologically sort the letter graph; a valid order exists iff there's no cycle (no contradiction).

Why only the FIRST difference is a real clue: once two words diverge, everything after that point is irrelevant to their relative order — like comparing "wrt" vs "wrf": the 't' vs 'f' at position 2 fully determines wrf < wrt, so nothing later matters. Continuing to compare past the first difference would add false or redundant edges.
The prefix trap: if a longer word appears before a shorter word that's its own prefix — like "abc" before "ab" — no valid alphabet can explain that (a shorter prefix must always sort first). This case has to be checked explicitly; it produces no differing letter to build an edge from, so it would otherwise slip through undetected.

Optimal Solution — Build Graph From First Differences + Kahn's · O(total characters) time, O(unique letters + edges) space

from collections import defaultdict, deque

def alien_order(words):
    graph = defaultdict(set)
    indeg = {c: 0 for w in words for c in w}
    for a, b in zip(words, words[1:]):
        minlen = min(len(a), len(b))
        if len(a) > len(b) and a[:minlen] == b[:minlen]:
            return ""                       # prefix contradiction -> impossible
        for j in range(minlen):
            if a[j] != b[j]:                # FIRST difference is the only real clue
                if b[j] not in graph[a[j]]:
                    graph[a[j]].add(b[j]); indeg[b[j]] += 1
                break

    q = deque([c for c in indeg if indeg[c] == 0])
    order = []
    while q:
        c = q.popleft(); order.append(c)
        for nxt in graph[c]:
            indeg[nxt] -= 1
            if indeg[nxt] == 0:
                q.append(nxt)

    return "".join(order) if len(order) == len(indeg) else ""   # leftover letters -> cycle

Comparing adjacent words is proportional to total characters → O(total characters) time. Graph over unique letters → O(unique letters + edges) space.
