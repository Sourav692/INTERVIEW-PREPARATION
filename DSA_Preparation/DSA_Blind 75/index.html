How to use this

Each problem page has the idea in plain words and an interactive diagram — press ▶ Play or step with Prev / Next.

Each topic’s cheat sheet (🧩) lists the handful of patterns behind its problems, how to spot each one, and a sentence to say in an interview.

Each topic's README.md (📚) teaches the ideas behind that topic in plain language with mermaid diagrams — read it before starting a topic.

Each problem's notebook (in the same topic folder) holds the full Python solutions (worst → optimal), correctness tests, and empirical Big-O benchmarks.

Tip: everything works offline — just double-click any index.html.
