Prefix & Suffix Products

Product of Array Except Self — two directional sweeps instead of division

The core flip

The answer for index i splits cleanly into two independent halves: (product of everything to its left) × (product of everything to its right). Precompute the running product from the left in one pass, then the running product from the right in a second pass — no division needed, which matters because division is disallowed and breaks on zeros.

Why the output array can double as scratch: Pass 1 writes out[i] = prefix (product of everything strictly left of i) — this only ever reads nums, never out, so it's safe. Pass 2 then multiplies in the suffix product walking right to left. No second array is needed — that's what keeps extra space at O(1).

Optimal Solution — Prefix × Suffix, No Division · O(n) time, O(1) extra space

def product_except_self(nums: list[int]) -> list[int]:
    n = len(nums)
    out = [1] * n

    prefix = 1                    # running product of everything to the LEFT
    for i in range(n):
        out[i] = prefix           # product of all elements before i
        prefix *= nums[i]         # extend the running left-product

    suffix = 1                    # running product of everything to the RIGHT
    for i in range(n - 1, -1, -1):     # sweep right to left
        out[i] *= suffix          # multiply in product of all elements after i
        suffix *= nums[i]         # extend the running right-product

    return out

Two linear passes, O(1) work per element → O(n) time. The output array is reused as scratch space, so only two running scalars are extra → O(1) extra space (output itself isn't counted).

Why not just divide? Multiply everything, then divide by nums[i] — tempting, but the problem forbids division, and it breaks on zeros: with two or more zeros every output is 0 anyway, but with exactly one zero only that slot survives, requiring special-case handling either way. Prefix × suffix sidesteps all of it.
