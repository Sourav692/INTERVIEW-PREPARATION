BFS, DFS, and counting connected components — all on a visited set.

The one thing trees didn’t need: a visited set

Graphs have cycles, so a blind walk loops forever. A visited set — mark a vertex the first time you see it — makes traversal safe and O(V+E).

BFS = queue = wide = shortest path. DFS = stack = deep = structure (cycles, order, components). Same code, different container.
