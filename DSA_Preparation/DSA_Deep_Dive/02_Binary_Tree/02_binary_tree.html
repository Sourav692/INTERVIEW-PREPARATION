🌲 Binary Trees

At most two ordered children — array packing, invert, and diameter.

The idea & shapes

A binary tree: every node has at most two ordered children (left, right).

Shapes: full (0 or 2 children), complete (levels fill left→right), perfect (full + all leaves same depth), balanced (heights differ ≤ 1), skewed (a linked list).

① Array packing (how a heap is stored)

A complete tree needs no pointers: index i has left=2i+1, right=2i+2, parent=(i−1)/2.

the same tree as an array

② Invert / mirror the tree

Swap every node’s left and right child. Watch the tree mirror (its in-order reverses). LeetCode 226.

③ Diameter — the longest path

The longest path between any two nodes (it may skip the root). A DFS returns each node’s height while tracking the best left+right.
