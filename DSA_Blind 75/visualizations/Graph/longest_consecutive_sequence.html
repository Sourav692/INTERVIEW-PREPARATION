128 · Longest Consecutive Sequence

Longest run of consecutive numbers.

The problem, in plain words

Find the longest run of consecutive whole numbers (like 1,2,3,4) hidden in an unsorted list — without sorting.

Example: [100,4,200,1,3,2] → 4 (1,2,3,4).
looking atremembered / keptmatch / answerruled out

The smart way — grow each run from its start

Put every number in a set (instant lookups). A number is the start of a run only if the number before it is missing. From each start, count upward while the next number exists. Each number is touched about once.

all numbers (set)

Speed: one pass with instant lookups — O(n) (sorting would be O(n log n)).

When you'd use this

See "longest run of consecutive numbers, O(n)"? Use a set and only grow runs from their true start.
