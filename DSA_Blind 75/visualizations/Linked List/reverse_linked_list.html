206 · Reverse Linked List

Flip a list around.

The problem, in plain words

Reverse a linked list — make every arrow point the other way.

1→2→3 becomes 3→2→1.
looking atremembered / keptmatch / answerruled out

The smart way — flip arrows, dragging a "prev" along

Keep a prev pointer (starts empty). At each node, remember the next node, point this node back at prev, then move prev and the cursor forward.

Speed: one pass — O(n), no extra memory.

When you'd use this

See "reverse a list / part of it"? Flip arrows with a prev pointer — O(n), O(1).
