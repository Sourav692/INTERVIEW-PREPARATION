102 · Binary Tree Level Order Traversal

Read the tree row by row.

The problem, in plain words

List the values level by level, top to bottom, left to right.

Example: → [[3],[9,20],[15,7]].
looking atremembered / keptmatch / answerruled out

The smart way — BFS with a queue

The queue always holds exactly one level. Empty it into a row, pushing each node’s children for the next level. Repeat until the queue is empty.

result so far

Speed: one visit per node — O(n) time.

When you'd use this

See "level order / by depth / row by row"? Use a queue and process one level at a time.
