Fewest coins to make an amount.

The problem, in plain words

Using coins of given values (reusable), make a target amount with the fewest coins.

Example: coins [1,3,4], amount 6 → 2 coins (3+3). Greedy 4+1+1 would use 3 — worse!
looking atremembered / keptmatch / answerruled out

The smart way — build every amount from smaller amounts

Fewest coins for amount a = 1 + the fewest for (a − coin), tried over every coin. Fill amounts 0,1,2,… so each reuses answers already computed.
fewest coins for each amount (∞ = not yet possible)

Speed: O(amount × coins). Greedy can be wrong, so we try all coins.

When you'd use this

See "fewest / number of ways to make a target from reusable parts"? Build every amount from smaller amounts — don’t trust greedy.
