62 · Unique Paths

Count grid paths (right/down).

The problem, in plain words

A robot at the top-left moves only right or down. How many paths reach the bottom-right?

Example: 3×7 grid → 28 paths.
looking atremembered / keptmatch / answerruled out

The smart way — each cell = paths from above + from the left

A cell can only be entered from the cell above or the one to its left, so its path count is the sum of those two. The top row and left column are all 1 (only one way along an edge).

Speed: fill each cell once — O(rows×cols).

When you'd use this

See "count paths in a grid moving right/down"? Grid DP: each cell = the cell above + the cell to the left.
