6 · Group Anagrams

Bucket the anagrams together.

The problem, in plain words

Put words that are anagrams of each other into the same group.

Example: ["eat","tea","tan","ate","nat","bat"] → ["eat","tea","ate"], ["tan","nat"], ["bat"].
looking atremembered / keptmatch / answerruled out

The smart way — a shared fingerprint

Give each word a fingerprint that all its anagrams share — its letters in sorted order. Words with the same fingerprint drop into the same bucket.

Speed: one fingerprint per word — O(n · k) with a count fingerprint (or O(n · k log k) if you sort).

When you'd use this

See "group things equivalent under some change"? Give each a canonical fingerprint and bucket by it in a hash map.
