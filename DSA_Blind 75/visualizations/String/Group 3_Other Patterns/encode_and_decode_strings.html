9 · Encode and Decode Strings

Pack a list into one string, safely.

The problem, in plain words

Pack a list of strings into one string, then unpack it back — perfectly, even if the strings contain any character.

Trick: write each string’s length before it, like "4#lint". To read back, read the number, then take exactly that many characters.

Decoding — read the length, then read that many characters

The encoded text looks like "4#lint4#code3#a#b". Read digits up to the # to get a length, then grab exactly that many characters as one string. Repeat. The length tells you where each piece ends, so the data can safely contain #.
