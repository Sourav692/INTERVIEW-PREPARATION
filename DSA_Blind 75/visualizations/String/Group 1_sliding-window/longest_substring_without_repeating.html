4 · Longest Substring Without Repeating Characters

Longest run with no repeats.

The problem, in plain words

Find the longest stretch of the text that has no repeated character.

Example: "abcabcbb" → 3 (the "abc").   "bbbbb" → 1.
looking atremembered / keptmatch / answerruled out

The smart way — a sliding window of unique letters

Keep a window that always holds only unique letters. Grow it on the right. If the new letter is already inside, slide the left edge forward until the repeat is gone. Track the biggest window.

letters in the window

Speed: each letter enters and leaves once — O(n) time.
