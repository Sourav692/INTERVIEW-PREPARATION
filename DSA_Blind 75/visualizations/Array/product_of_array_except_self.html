4 · Product of Array Except Self

Multiply all the others — no division.

The problem, in plain words

For each spot, multiply all the other numbers together (everything except the one you’re standing on). Do it without dividing.

Example: [1, 2, 3, 4] → [24, 12, 8, 6]. (For the first spot: 2×3×4 = 24.)

The smart way — two sweeps: left, then right

First sweep left → right: fill each answer with the product of everything to its left. Then sweep right → left, multiplying in the product of everything to its right. A single running number carries the product as you go.

Speed: two passes — O(n) time, no extra memory beyond the answer. (The obvious way multiplies others each time: O(n²).)

When you'd use this

See "combine everything except this one" or range products/sums? Precompute running results from the left and right, then combine.
