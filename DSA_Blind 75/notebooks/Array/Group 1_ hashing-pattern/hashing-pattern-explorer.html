The core flip

Instead of asking "for this pair, do they sum to target?" (checking every pair), ask "I have x — have I already seen target − x?" One pass, one hash-map lookup per element.

nums = [2, 7, 11, 15]  target = 9

Why check before inserting: if we inserted x first, then looked up target − x, an element could pair with itself when target == 2*x. Checking the map before adding the current element is what prevents reusing the same index twice.

Optimal Solution — O(n) time, O(n) space

def two_sum(nums: list[int], target: int) -> list[int]:
    seen = {}                    # value -> index, for numbers already passed
    for i, x in enumerate(nums):
        need = target - x        # the partner that would complete the pair
        if need in seen:          # already passed that partner?
            return [seen[need], i]
        seen[x] = i               # remember x so a future number can find it
    return []                     # (never reached: a solution is guaranteed)

Single pass, O(1) map lookups → O(n) time. The map holds up to n entries → O(n) space.

The core flip

A duplicate exists iff, while scanning left to right, you ever meet a value you've already recorded. A hash set answers "seen before?" in O(1) — no complement needed, just membership.

nums = [1, 2, 3, 1]
Hash Set (seen so far)
Press "Step" to begin. i = 0, x = nums[0] = 1.
current element duplicate found already scanned
Why not a list? x in some_list is an O(n) scan every time, so the whole algorithm degrades back to O(n²). A set's O(1) average membership test is what makes the single pass genuinely O(n).

Optimal Solution — O(n) time, O(n) space

def contains_duplicate(nums: list[int]) -> bool:
    seen = set()               # values already encountered
    for x in nums:
        if x in seen:           # already met this value -> duplicate
            return True
        seen.add(x)             # otherwise remember it and continue
    return False

Single pass, O(1) average set operations → O(n) time. Set holds up to n values → O(n) space.
