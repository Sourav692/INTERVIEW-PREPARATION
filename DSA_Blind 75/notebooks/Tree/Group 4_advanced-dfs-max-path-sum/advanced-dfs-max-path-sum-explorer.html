Advanced DFS: Return One Thing, Track Another

Binary Tree Maximum Path Sum — the DFS returns a single arm, but updates a global "bent path" answer along the way

The core flip

A path can bend at any node — come up the left subtree, pass through the node, go down the right subtree. So at each node, two different questions get answered simultaneously:

  • What's the best "bent" path through this node? → node.val + best_left_arm + best_right_arm — used only to update a global best, since a bent path can't be extended further by a parent.
  • What's the best single arm I can hand my parent? → node.val + max(best_left_arm, best_right_arm) — a parent can only attach one straight branch, not two.

Why clamp negative arms to zero: max(0, gain(child)) means "if this branch would only hurt the sum, don't take it — treat it as contributing nothing rather than something negative." This is what correctly handles a node like -10 at the root: its own value is so negative that including it in any path would only make things worse, so the best path skips right past it and lives entirely in the right subtree (15 → 20 → 7 = 42).
The single most common bug: returning the bent (two-arm) value up to the parent instead of the single-arm value. A parent receiving a two-arm value would be tempted to add a third branch on top of it — but a real tree path can't fork twice. The function must return node.val + max(left, right), never node.val + left + right.

Optimal Solution — One-Pass DFS · O(n) time, O(h) space

def max_path_sum(root):
    best = [float("-inf")]           # global answer, found anywhere in the tree

    def gain(node):                  # returns the best single downward arm from `node`
        if not node:
            return 0
        left = max(0, gain(node.left))    # clamp: skip a branch that would hurt
        right = max(0, gain(node.right))
        best[0] = max(best[0], node.val + left + right)   # bent path through this node
        return node.val + max(left, right)                 # but hand parent only ONE arm

    gain(root)
    return best[0]

Every node visited once, O(1) work per node → O(n) time. Recursion stack depth = tree height → O(h) space.
