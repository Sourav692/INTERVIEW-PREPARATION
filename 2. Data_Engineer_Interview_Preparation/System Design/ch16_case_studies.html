The Simple Version, First

These aren't four disconnected designs. Each case study is a different hard ceiling dressed as a familiar prompt — and the interview signal is whether you name that ceiling in the first five minutes.

Work them in order if you can: fraud → recommendations → clickstream → IoT. The transferable patterns stack.

How to use these in interview prep

  1. Read the prompt, then pause and name the ceiling out loud before drawing boxes.
  2. Compare your clarifying questions to the transcript — that's where mid-level vs senior separates.
  3. Photograph the cheat sheet at the end of each case study the night before.
  4. If a pattern feels familiar, jump back to the chapter it came from (linked in each write-up).
