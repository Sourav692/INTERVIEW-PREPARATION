# Agentic System Design

Generic, reusable system-design build-outs used across interview prep:

- **`agent_platform/`** — deterministic-control-flow AI agent platform (guardrails, tool calling, tenancy).
- **`enterprise_rag_platform/`** — enterprise RAG with access control (Meridian Assist).
- **`delivery_framework_platform/`** — gated, seven-stage delivery pipeline.
- **`cross_cutting_prep/`** — identity/secrets, observability, cost/latency/CI-CD, and tool-call guardrail material that applies across all three projects.

**DevRev-specific prep** (the prep doc, study guide, and reading-order checklist that map DevRev's system
design round onto the projects above) lives in
[`../DevRev_Preparation/System_Design_Round/`](../DevRev_Preparation/System_Design_Round/) — start there
if you're prepping for DevRev specifically.
